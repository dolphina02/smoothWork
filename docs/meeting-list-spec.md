# Meeting 화면 기능명세

## 1. 목적

Yesterday의 미팅 탭(digest-spec.md 5절)이 "어제 하루"로 스코프가 좁혀진 브라우징이라면, 이
화면은 동기화된 Outlook 일정 **전체(과거+미래)**를 검색·훑어보는 용도다. 미팅 상세(요약/원문
뷰어)는 Digest 5.2절의 컴포넌트를 그대로 재사용한다 — 이 문서는 "여러 날짜의 미팅을 어떻게
나열하고 찾는가"만 다룬다.

## 2. 레이아웃

```
┌───────────────────┬──────────────────────────────────────────┐
│ [검색] [기간: 이번주▾]│ 우측: 선택 미팅 상세                          │
│ ────────────────── │        (Digest 5.2절 컴포넌트 재사용)         │
│ 8/10 (월)           │                                            │
│  ○ 10:00 스프린트 회의│                                            │
│ 8/11 (화)           │                                            │
│  ○ 11:00 1:1 이은지  │                                            │
│  ○ 15:00 리팩토링 리뷰│                                            │
│ 8/12 (수) 오늘       │                                            │
│  ○ 10:00 위클리 싱크  │                                            │
│  ● 14:00 고객 미팅    │                                            │
│ ...                 │                                            │
└───────────────────┴──────────────────────────────────────────┘
```

- 좌측: 날짜별로 그룹핑된 평면 리스트 (Digest의 리스트-상세 패턴과 동일하되, 하루가 아니라
  여러 날짜를 세로로 이어서 나열)
- 우측: 선택된 미팅의 상세 — Digest 5.2절(요약 카드, 원본 보기, 다시 생성, "후속 작업 N건"
  카운터)을 그대로 재사용
- 기본 스크롤 위치는 "오늘"에 가장 가까운 미팅

## 3. 필터 / 검색

- **검색**: 제목/참석자 키워드
- **기간**: 이번 주(기본) / 이번 달 / 전체 / 커스텀 범위
- 정렬: 시각 오름차순 고정

## 4. 미래 미팅

- 아직 발생하지 않은 일정도 그대로 나열된다 — 녹음/요약이 없으므로 Digest 5.2절의 "녹음 없음"
  안내가 그대로 적용되고, 참석자 정보만 보인다
- 미래 미팅에는 "후속 작업 N건" 카운터를 표시하지 않는다 (아직 아무 발화도 없으므로 의미가 없음)

## 5. Yesterday 화면과의 교차 이동

- 과거 미팅의 상세에서 "후속 작업 N건"을 누르면 Yesterday 화면(digest-spec.md 7절)의 Follow-up
  Task 탭으로 이동한다 — 이때 그 미팅이 속한 날짜로 Yesterday의 날짜 네비게이터를 함께 이동시켜
  연다 (Yesterday는 항상 "선택된 날짜" 기준으로 필터링되므로, 임의 과거 날짜의 미팅에서 넘어올
  때도 날짜 파라미터를 함께 전달해야 정확한 후속 작업 목록이 보인다)

## 6. 엣지 케이스

- **동기화된 일정이 하나도 없음**: "Outlook과 연동된 일정이 없습니다" 안내 + Configuration
  화면(configuration-spec.md) 바로가기
- **취소된 일정** (`calendar_cancelled=true`, backend-api-spec.md 2.3절): 리스트에 "취소됨"
  뱃지와 함께 흐리게 표시. 기본 필터에서는 숨기고, "취소된 일정 포함" 토글로만 노출한다
